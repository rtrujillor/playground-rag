Contains the planned Vue.js single-page application (SPA), providing the user-facing entry point to the RAG system. Users will upload documents, follow ingestion status, and ask questions about processed content, viewing answers with supporting source citations through the backend API. Start with a small dependency set and prepare for production through modular components, responsive and accessible interfaces, clear loading and error states, environment-based API configuration, and automated checks. The frontend tooling and dependencies are pending selection; no application dependencies are installed yet. Python backend dependencies remain managed with uv, while frontend dependencies will use a JavaScript package manager.
